# ESEP Grade Calculator

This library is a simple utility to calculate your grades. Grade are calculated based on the weighted amount in each grade category. The final grade is the weighted average of all assignments.

Runtime requirements:
Golang 1.24+
Download GO

Run unit tests:
```
cd grade-calculator
go test
```

Run unit tests with code coverage:
```
cd grade_calculator/
go test -coverprofile=coverage.txt ./...
```
